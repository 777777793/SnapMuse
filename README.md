# SnapMuse

SnapMuse 是一个基于 Java 17 + Spring Boot 的本地截图 AI 问答工具。

长按鼠标框选屏幕区域，截图自动发送给 AI，回答实时流式显示在本地网页，手机平板可同局域网查看。

## 环境要求

- Java 17
- Maven 3.9+
- macOS（需要辅助功能 / 输入监控 / 屏幕录制权限）

## 启动

```bash
mvn spring-boot:run
```

启动后浏览器打开：

```
http://127.0.0.1:8080
```

首次启动自动生成数据目录：

```
snapmuse-data/
├── config.json       # 本地配置
├── history.json      # 对话历史
└── screenshots/      # 截图文件
```

## macOS 权限

通过 IntelliJ IDEA 启动 → 给 `IntelliJ IDEA` 开权限；通过终端启动 → 给 `Terminal` / `iTerm` 开权限。

| 权限 | 用途 |
|------|------|
| 辅助功能 | 全局监听鼠标长按 |
| 输入监控 | 捕获全局鼠标事件 |
| 屏幕录制 | 截取桌面图像 |

## 基本使用

1. 进入网页设置，配置 API 接口（支持所有 OpenAI 协议兼容接口）
2. 长按鼠标左键 **2 秒**记录第一个角点
3. 再长按鼠标左键 **2 秒**记录第二个角点
4. 截图自动发送给 AI，回答流式显示在页面中

> 第一个点记录后 5 秒内未选第二个点，自动清除重来。

## 工具栏说明

| 元素 | 说明 |
|------|------|
| 状态灯 | 灭 = 空闲；黄 = 等待第二个点；绿 = AI 回答中 |
| 模型按钮 | 显示当前接口名，点击打开选择器 |
| 降级勾选 | 每个接口右侧可勾选是否加入降级列表，勾选多个时按从上到下顺序依次尝试；只勾一个等同于不降级 |
| 停止按钮 | AI 回答中可点，中断当前请求 |
| 清空按钮 | 清除所有对话记录 |
| 设置按钮 | 打开设置面板 |

## 模型与降级

- 点击模型按钮，在弹出列表中**点击接口名**切换主模型
- 每个接口右侧有**降级**勾选框，勾选多个接口即启用降级
- 主模型请求失败时，自动按降级列表顺序重试，气泡内会显示加载动画及"正在降级切换至：xxx"提示
- AI 气泡顶部显示**实际回答的接口名**，降级后会变为降级到的接口名

## 流式输出

回答采用流式推送，模型开始输出后即可在页面实时看到文字逐步显示，无需等待全部生成完毕。

## 跨设备查看

同一局域网下，用运行 SnapMuse 的电脑 IP 加 `8080` 在其他设备浏览器中访问：

```
http://192.168.x.x:8080
```

手机、平板均可实时查看回答内容。

## 设置项

| 设置 | 说明 |
|------|------|
| API 配置 | 最多 5 组，每组填写名称、Base URL、API Key、模型名 |
| 系统提示词 | 全局系统 prompt，留空使用默认答题 prompt |
| 截图保存目录 | 截图文件存放路径 |
| 上滚 / 下滚快捷键 | 用键盘滚动网页对话区（默认 ALT+UP / ALT+DOWN） |
| 切换模型快捷键 | 快速循环切换主模型（默认 ALT+M） |
