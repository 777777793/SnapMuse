# SnapMuse

SnapMuse 是一个基于 Java 17 + Spring Boot 的本地截图 AI 问答工具。

它支持：

- 全局鼠标长按 2 秒选点截图
- 本地网页查看对话记录、状态灯和当前模型
- 配置 5 组 OpenAI 协议兼容 API
- 支持切换优先模型，并可选择是否自动降级到其他模型
- 自定义系统提示词、截图保存目录、上下滚动快捷键、模型切换快捷键

## 环境要求

- Java 17
- Maven 3.9+
- macOS 下建议使用 IntelliJ IDEA 或终端运行

## 启动

```bash
mvn spring-boot:run
```

启动后访问：

```text
http://127.0.0.1:8080
```

首次启动会自动生成运行目录：

```text
snapmuse-data/
```

其中会保存：

- `config.json`：本地配置
- `history.json`：对话记录
- `screenshots/`：截图文件

## macOS 权限

如果需要全局监听鼠标和桌面截图，请给运行宿主开启以下权限：

- 辅助功能
- 输入监控
- 屏幕录制

如果你是通过 IntelliJ IDEA 启动，请给 `IntelliJ IDEA` 开权限；如果是终端启动，请给 `Terminal` 或 `iTerm` 开权限。

## 使用方式

1. 打开网页，先进入设置页配置 5 组 API、模型、系统提示词和快捷键
2. 回到主页后，在底部工具栏可以看到状态灯、当前模型、降级开关和设置按钮
3. 如需切换优先模型，可以点击底部当前模型，或使用设置里配置的模型切换快捷键
4. 如果打开“允许降级”，会优先使用当前模型，失败后再依次尝试后续模型；如果关闭，则只使用当前模型
5. 直接长按鼠标左键 2 秒记录第一个点
6. 再长按鼠标左键 2 秒记录第二个点
7. 截图会自动发送给 AI，回答会显示在本地网页中，并自动滚动到最新内容

如果第一个点后 5 秒内没有选第二个点，首个点会自动清除。

## 跨设备查看

如果两台设备处于同一局域网，可以在运行 SnapMuse 的电脑上启动程序后，用它的本地 IP 加 `8080` 在另一台设备浏览器中打开结果页面，例如：

```text
http://192.168.1.100:8080
```

这样就可以在手机、平板或另一台电脑上查看回答内容。

## 状态灯说明

- 灭灯：当前处于空闲状态
- 黄灯：已经进入选点流程，或者已经记录了第一个点，正在等待第二个点
- 绿灯：截图已经提交，AI 正在分析并生成回答
